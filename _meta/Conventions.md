# Conventions

These rules keep notes reachable from [[00 Index]] and the generated [[_code/00 Code map]].

- Every note has YAML frontmatter with `title` and `tags`.
- Every note links to at least one other note. No orphans.
- Tag namespaces: `kind/`, `lang/`, `area/`, `role/`, `status/`.
- Auto-generated regions sit between `vaultify:auto` markers. Anything outside them is preserved across syncs — put your own prose there.
- Code companion notes live in `_code/` and mirror the source tree.
